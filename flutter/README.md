# Flutter

The planned Flutter package will live in this directory and publish directly to pub.dev.

Intended layout:

```text
flutter/
  lib/      # Dart API and Flutter widgets
  ios/      # Bridge to the native Swift implementation
  android/  # Bridge to the native Kotlin implementation
  example/  # Example Flutter application
```

Flutter development and pull requests remain in the `ccda-kit` monorepo. A separate source repository is not required.
