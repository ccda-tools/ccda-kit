# Notices

## Sample C-CDA Documents

Some example C-CDA XML files used by the sample app were downloaded from the public `chb/sample_ccdas` repository:

https://github.com/chb/sample_ccdas

That repository describes itself as containing sample C-CDA documents for developer use and not containing PHI. Keep all sample data synthetic or explicitly public/test-only.

Shared parser test data lives in `test-data/ccda/samples/` and includes files copied or downloaded from that public sample source.

## Healthcare Data Warning

Do not commit protected health information, real patient records, credentials, private certificates, or production clinical documents to this repository.
